## 🔄 Maven Build Lifecycle

Maven có 3 built-in lifecycles: **default**, **clean**, **site**. Quan trọng nhất là **default**:

```
validate → compile → test → package → verify → install → deploy
```

| Phase | Làm gì |
|-------|--------|
| `validate` | Kiểm tra project config hợp lệ |
| `compile` | Biên dịch source code → target/classes |
| `test` | Chạy unit tests (JUnit) |
| `package` | Đóng gói → target/app.jar |
| `verify` | Chạy integration tests |
| `install` | Copy JAR vào local repo (~/.m2) |
| `deploy` | Upload lên remote repo |

```bash
# Maven commands
mvn clean              # Xóa thư mục target/
mvn compile            # Chỉ compile
mvn test               # Compile + test
mvn package            # Compile + test + tạo JAR
mvn clean package      # Clean rồi package (dùng phổ biến nhất)
mvn clean package -DskipTests  # Bỏ qua tests (dùng khi cần nhanh)
mvn install            # Package + copy vào local repo
mvn spring-boot:run    # Chạy Spring Boot app trực tiếp
```

## ⚡ Gradle Tasks

Gradle không có lifecycle cứng như Maven — dùng Tasks có dependencies:

```
compileJava → processResources → classes
     ↓
compileTestJava → processTestResources → testClasses
     ↓
test
     ↓
jar / bootJar
     ↓
assemble → check → build
```

```bash
# Gradle commands (dùng ./gradlew)
./gradlew clean              # Xóa thư mục build/
./gradlew compileJava        # Chỉ compile
./gradlew test               # Chạy tests
./gradlew build              # Full build (compile + test + jar)
./gradlew clean build        # Clean rồi build
./gradlew build -x test      # Build bỏ qua tests
./gradlew bootJar            # Tạo executable Spring Boot JAR
./gradlew bootRun            # Chạy Spring Boot app
./gradlew dependencies       # Xem dependency tree
./gradlew tasks              # Xem tất cả available tasks
```

## 📦 Output: JAR vs WAR

```bash
# JAR (Java ARchive) — Self-contained, dùng cho microservices
java -jar target/my-app-1.0.0.jar

# Cấu hình JAR trong pom.xml
<packaging>jar</packaging>

# WAR (Web ARchive) — Deploy vào Tomcat/JBoss server
<packaging>war</packaging>

# Spring Boot Executable JAR — chứa embedded Tomcat
# Sau khi: mvn clean package
# Chạy:
java -jar target/my-app.jar
java -jar target/my-app.jar --spring.profiles.active=prod
java -jar target/my-app.jar --server.port=9090
```

## 🐳 Build Docker Image

```bash
# Cách 1: Dùng Dockerfile
docker build -t my-app:1.0 .

# Cách 2: Spring Boot Buildpacks (không cần Dockerfile)
./gradlew bootBuildImage --imageName=my-app:1.0
mvn spring-boot:build-image -Dspring-boot.build-image.imageName=my-app:1.0
```
