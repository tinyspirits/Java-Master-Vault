## 🔬 pom.xml Đầy Đủ (Spring Boot)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0
         https://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <!-- ① Parent — kế thừa default config từ Spring Boot -->
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.2.0</version>
        <relativePath/>
    </parent>

    <!-- ② Project Coordinates — định danh duy nhất -->
    <groupId>com.example</groupId>        <!-- tên tổ chức/domain ngược -->
    <artifactId>my-spring-app</artifactId> <!-- tên project -->
    <version>1.0.0-SNAPSHOT</version>      <!-- SNAPSHOT = đang phát triển -->
    <packaging>jar</packaging>             <!-- jar hoặc war -->

    <!-- ③ Properties — biến dùng lại -->
    <properties>
        <java.version>21</java.version>
        <mapstruct.version>1.5.5.Final</mapstruct.version>
    </properties>

    <!-- ④ Dependencies — thư viện cần thiết -->
    <dependencies>

        <!-- Web + REST API -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
            <!-- Không cần version — kế thừa từ parent BOM -->
        </dependency>

        <!-- JPA + Hibernate -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-jpa</artifactId>
        </dependency>

        <!-- Database driver -->
        <dependency>
            <groupId>org.postgresql</groupId>
            <artifactId>postgresql</artifactId>
            <scope>runtime</scope>  <!-- chỉ cần lúc runtime, không cần compile -->
        </dependency>

        <!-- Validation -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

        <!-- Lombok — code generation -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <scope>provided</scope>  <!-- chỉ cần compile time -->
        </dependency>

        <!-- Testing — chỉ dùng trong test -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-test</artifactId>
            <scope>test</scope>  <!-- không đóng gói vào JAR cuối -->
        </dependency>

    </dependencies>

    <!-- ⑤ Build Configuration -->
    <build>
        <plugins>
            <!-- Spring Boot Maven Plugin — tạo executable JAR -->
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
                <configuration>
                    <excludes>
                        <exclude>
                            <groupId>org.projectlombok</groupId>
                            <artifactId>lombok</artifactId>
                        </exclude>
                    </excludes>
                </configuration>
            </plugin>
        </plugins>
    </build>

</project>
```

---

## 📌 Dependency Scopes

| Scope | Compile | Test | Runtime JAR |
|-------|---------|------|------------|
| `compile` (default) | ✅ | ✅ | ✅ |
| `provided` | ✅ | ✅ | ❌ |
| `runtime` | ❌ | ✅ | ✅ |
| `test` | ❌ | ✅ | ❌ |
