## 🔨 Maven là gì?

**Apache Maven** là build automation tool cho Java — quản lý:
- **Dependencies** (tự động download JAR từ Maven Central)
- **Build Lifecycle** (compile → test → package → deploy)
- **Project Structure** (convention over configuration)

---

## 🌐 Maven Repository

```
Developer Machine
    ↓ tìm trong
Local Repository (~/.m2/repository)
    ↓ nếu không có
Central Repository (repo.maven.apache.org)
    ↓ hoặc
Remote Repository (Nexus, Artifactory — trong doanh nghiệp)
```

---

## 📁 Standard Directory Layout (Maven Convention)

```
my-project/
├── pom.xml
└── src/
    ├── main/
    │   ├── java/         ← source code
    │   └── resources/    ← config files, templates
    └── test/
        ├── java/         ← test code
        └── resources/    ← test resources
```

> 💡 Maven "hiểu" cấu trúc này mà không cần config thêm. Xem chi tiết → [[03.1 Spring Boot Project Layout]]
