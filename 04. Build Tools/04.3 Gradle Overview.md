## 🐘 Gradle là gì?

**Gradle** là build tool thế hệ mới — linh hoạt hơn Maven, dùng Groovy/Kotlin DSL thay XML. Được ưa chuộng cho Android và các project Spring Boot hiện đại.

---

## 🆚 Gradle vs Maven

| | Maven | Gradle |
|--|-------|--------|
| Config format | XML (pom.xml) | Groovy/Kotlin DSL |
| Tốc độ | Trung bình | **Nhanh hơn** (incremental, cache) |
| Flexibility | Convention-based | Highly customizable |
| Learning curve | Dễ hơn | Cao hơn một chút |
| Android | ❌ | ✅ Official |
| Spring Boot | ✅ | ✅ |

> 💡 **Dự án này dùng Gradle** — xem [[04.4 build.gradle Structure]] để hiểu cấu trúc thực tế.

---

## ⚡ Gradle Wrapper (Khuyên dùng)

```bash
# Dùng gradlew thay vì gradle trực tiếp
# → Đảm bảo cùng version Gradle cho mọi developer
./gradlew build    # macOS/Linux
gradlew.bat build  # Windows
```
