## 🗑️ GC là gì?

**Garbage Collection** là cơ chế tự động thu hồi vùng nhớ Heap mà không còn object nào **reachable** (có thể truy cập từ GC Roots) nắm giữ nữa. Lập trình viên Java **không cần gọi `free()`** như C/C++.

---

## 📍 GC Roots — Điểm Xuất Phát

GC bắt đầu từ các "roots" sau để tìm object còn sống:
- Local variables trong Stack
- Static variables trong Method Area
- Active threads
- JNI references

---

## 🔄 Quy Trình GC — Generational Collection

```
Heap
├── Young Generation  ← Minor GC (nhanh, thường xuyên)
│   ├── Eden          ← new Object() sinh ra đây
│   ├── Survivor S0
│   └── Survivor S1
└── Old Generation   ← Major/Full GC (chậm, hiếm)
```

**Vòng đời của một object:**
```
new Object()
    → Eden (Minor GC sau vài lần survive → S0/S1)
    → Sau ~15 lần survive → Old Generation
    → Full GC dọn Old Gen khi đầy
```

## ⚙️ Các Thuật Toán GC Chính

| GC | Từ Java | Phù hợp | Đặc điểm |
|----|---------|---------|---------|
| **Serial GC** | Java 1 | App nhỏ, single-core | 1 thread, stop-the-world |
| **Parallel GC** | Java 5 | Throughput cao | Multi-thread, stop-the-world |
| **G1 GC** | Java 9 (default) | Balanced | Region-based, predictable pause |
| **ZGC** | Java 15 | Low-latency | Pause < 1ms, scalable |
| **Shenandoah** | Java 12 | Low-latency | Red Hat, concurrent compaction |

```bash
# Chọn GC khi chạy
java -XX:+UseG1GC          MyApp  # G1 (default từ Java 9)
java -XX:+UseZGC            MyApp  # ZGC (Java 15+)
java -XX:+UseShenandoahGC   MyApp  # Shenandoah
```

---

## 🔧 Tuning GC Cơ Bản

```bash
java -Xms512m              # Initial heap size
     -Xmx2g               # Max heap size
     -XX:+UseG1GC
     -XX:MaxGCPauseMillis=200   # Target max pause time
     -XX:+PrintGCDetails        # Log GC details
     -Xlog:gc*:file=gc.log      # Java 9+ logging
     MyApp
```

## ⚠️ Anti-Patterns

```java
// ❌ ĐỪNG làm thế này — System.gc() chỉ là gợi ý, không đảm bảo
System.gc();

// ❌ finalize() đã bị deprecated từ Java 9
@Override
protected void finalize() { ... }

// ✅ Dùng try-with-resources để giải phóng tài nguyên
try (InputStream is = new FileInputStream("file.txt")) {
    // tự động close khi ra khỏi block
}
```
