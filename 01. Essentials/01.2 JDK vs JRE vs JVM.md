## 🎯 Tóm Tắt Nhanh

```
JDK (Java Development Kit)  ← Dành cho DEVELOPER
 └── JRE (Java Runtime Environment)  ← Dành cho END USER
      └── JVM (Java Virtual Machine)  ← Máy ảo thực thi bytecode
```

> **Quy tắc:** Muốn **viết** Java → cần JDK. Muốn **chạy** Java → chỉ cần JRE. JVM là trái tim bên trong.

---

## 📊 So Sánh Chi Tiết

| Thành phần | Bao gồm | Dùng khi nào |
|-----------|---------|-------------|
| **JVM** | Execution Engine, Memory Manager, GC | Thực thi bytecode `.class` |
| **JRE** | JVM + Class Libraries (rt.jar) | Deploy app cho end-user |
| **JDK** | JRE + `javac`, `javadoc`, `jdb`, `jar`, `jps`... | Phát triển ứng dụng Java |

---

## 🛠️ JDK — Bộ Công Cụ Developer

```bash
# Các tool quan trọng trong JDK
javac HelloWorld.java    # Compile .java → .class (bytecode)
java  HelloWorld         # Chạy chương trình (gọi JVM)
jar   cf app.jar *.class # Đóng gói thành JAR
javadoc HelloWorld.java  # Sinh tài liệu HTML
jdb   HelloWorld         # Debug chương trình
jps                      # Xem các Java process đang chạy
jmap                     # Heap dump
jstack                   # Thread dump
```

---

## ⚠️ Lưu Ý Từ Java 11+

Từ **Java 11**, Oracle không còn distribute JRE riêng lẻ nữa. Bạn chỉ cần cài **JDK** — nó đã bao gồm mọi thứ. Để tạo runtime nhỏ gọn cho production, dùng **`jlink`**:

```bash
# Tạo custom runtime chỉ chứa các module cần thiết
jlink --add-modules java.base,java.sql \
      --output my-runtime \
      --compress=2
```
