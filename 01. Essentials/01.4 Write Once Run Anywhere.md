## 💡 Triết Lý Cốt Lõi

**"Write Once, Run Anywhere" (WORA)** — Viết code một lần, chạy được trên mọi hệ điều hành và phần cứng mà không cần biên dịch lại. Đây là lý do Sun Microsystems tạo ra Java năm 1995.

---

## 🔑 Chìa Khóa: Bytecode

```
                  [Bytecode - Platform Independent]
                           ↕
HelloWorld.java ──javac──▶ HelloWorld.class ──┬──▶ JVM trên Windows
                                              ├──▶ JVM trên Linux  
                                              ├──▶ JVM trên macOS
                                              └──▶ JVM trên Android (Dalvik/ART)
```

- **Source code** (`.java`) → biên dịch bởi `javac` → **Bytecode** (`.class`)
- Bytecode là ngôn ngữ trung gian, **không phải machine code** của bất kỳ CPU nào
- Mỗi OS/Platform cài một **JVM riêng** — JVM đó chịu trách nhiệm chuyển bytecode sang native code

---

## 🆚 So Sánh Với C/C++

| | Java | C/C++ |
|--|------|-------|
| Biên dịch | `.java` → bytecode | `.c` → native binary |
| Chạy trên platform khác | Cần JVM tương ứng | Phải biên dịch lại |
| Performance | JIT → gần native | Native speed |
| Portability | ✅ Cao | ❌ Thấp |

---

## ⚠️ Giới Hạn Thực Tế

> WORA không có nghĩa là 100% perfect:
- Code phụ thuộc vào **filesystem path** sẽ khác giữa Windows/Linux
- **Native libraries** (JNI) phải compile riêng cho từng platform
- Một số GUI behavior khác nhau trên từng OS
