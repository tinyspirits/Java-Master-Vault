## 🔒 1. Encapsulation — Đóng Gói

> **Ý tưởng:** Che giấu data bên trong, chỉ expose thông qua methods được kiểm soát.

```java
// ❌ BAD — field public, ai cũng thay đổi được
public class BankAccount {
    public double balance = 1000;  // nguy hiểm!
}

// ✅ GOOD — Encapsulation đúng cách
public class BankAccount {
    private double balance;  // ẩn field
    private String owner;

    public BankAccount(String owner, double initialBalance) {
        this.owner = owner;
        this.balance = initialBalance;
    }

    // Controlled access
    public double getBalance() {
        return balance;
    }

    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("Amount must be positive");
        this.balance += amount;
    }

    public void withdraw(double amount) {
        if (amount > balance) throw new IllegalStateException("Insufficient funds");
        this.balance -= amount;
    }
}
```

**Access Modifiers:**
| Modifier | Cùng class | Cùng package | Subclass | Bên ngoài |
|----------|-----------|-------------|---------|----------|
| `private` | ✅ | ❌ | ❌ | ❌ |
| `(default)` | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

## 🧬 2. Inheritance — Kế Thừa

> **Ý tưởng:** Class con kế thừa attributes & methods từ class cha, tránh duplicate code.

```java
// Superclass (class cha)
public class Animal {
    protected String name;
    protected int age;

    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void eat() {
        System.out.println(name + " is eating");
    }

    public String describe() {
        return name + ", age " + age;
    }
}

// Subclass (class con) — kế thừa Animal
public class Dog extends Animal {
    private String breed;

    public Dog(String name, int age, String breed) {
        super(name, age);  // gọi constructor của cha
        this.breed = breed;
    }

    // Thêm behavior riêng
    public void bark() {
        System.out.println(name + " says: Woof!");
    }

    // Override method của cha
    @Override
    public String describe() {
        return super.describe() + ", breed: " + breed;
    }
}

// Sử dụng
Dog dog = new Dog("Buddy", 3, "Labrador");
dog.eat();       // kế thừa từ Animal → "Buddy is eating"
dog.bark();      // method riêng → "Buddy says: Woof!"
dog.describe();  // override → "Buddy, age 3, breed: Labrador"
```

> ⚠️ **Java chỉ hỗ trợ Single Inheritance** (1 class chỉ extends 1 class). Dùng [[02.4 Interfaces & Abstract Classes]] để có multiple inheritance behavior.

## 🎭 3. Polymorphism — Đa Hình

> **Ý tưởng:** Cùng một interface/method nhưng hành vi khác nhau tùy loại object.

### Runtime Polymorphism (Method Overriding)

```java
public class Shape {
    public double area() {
        return 0;
    }
}

public class Circle extends Shape {
    private double radius;
    
    public Circle(double radius) { this.radius = radius; }

    @Override
    public double area() {
        return Math.PI * radius * radius;
    }
}

public class Rectangle extends Shape {
    private double width, height;
    
    public Rectangle(double w, double h) { width = w; height = h; }

    @Override
    public double area() {
        return width * height;
    }
}

// 🌟 Polymorphism in action — cùng kiểu Shape, khác behavior
List<Shape> shapes = List.of(
    new Circle(5),
    new Rectangle(4, 6),
    new Circle(3)
);

// Không cần biết cụ thể là Circle hay Rectangle
for (Shape shape : shapes) {
    System.out.println("Area: " + shape.area());  // gọi đúng method của từng class
}
// Output:
// Area: 78.53981...
// Area: 24.0
// Area: 28.27433...
```

### Compile-time Polymorphism (Method Overloading)

```java
public class Calculator {
    // Cùng tên, khác tham số → Overloading
    public int add(int a, int b) { return a + b; }
    public double add(double a, double b) { return a + b; }
    public int add(int a, int b, int c) { return a + b + c; }
    public String add(String a, String b) { return a + b; }
}
```

## 🌫️ 4. Abstraction — Trừu Tượng

> **Ý tưởng:** Ẩn đi implementation details, chỉ expose những gì cần thiết.

```java
// Abstract class — định nghĩa "khung" chung
public abstract class Vehicle {
    protected String brand;

    public Vehicle(String brand) {
        this.brand = brand;
    }

    // Abstract method — buộc subclass phải implement
    public abstract void startEngine();
    public abstract int getMaxSpeed();

    // Concrete method — dùng chung cho tất cả
    public void displayInfo() {
        System.out.println(brand + " | Max Speed: " + getMaxSpeed() + " km/h");
    }
}

public class ElectricCar extends Vehicle {
    public ElectricCar(String brand) { super(brand); }

    @Override
    public void startEngine() {
        System.out.println("Silent electric motor started...");
    }

    @Override
    public int getMaxSpeed() { return 250; }
}

public class GasCar extends Vehicle {
    public GasCar(String brand) { super(brand); }

    @Override
    public void startEngine() {
        System.out.println("Vroom! Gas engine started!");
    }

    @Override
    public int getMaxSpeed() { return 220; }
}
```

## 🏗️ Áp Dụng Trong Thực Chiến (Spring Boot)

OOP là nền tảng của [[03.2 Layered Architecture]]:

```java
// ---- ABSTRACTION: Interface định nghĩa contract ----
public interface UserService {
    UserDTO findById(Long id);
    UserDTO create(CreateUserRequest request);
}

// ---- ENCAPSULATION: Service hide business logic ----
@Service
public class UserServiceImpl implements UserService {
    
    private final UserRepository userRepository;  // private field
    
    // Constructor injection (best practice)
    public UserServiceImpl(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    @Override
    public UserDTO findById(Long id) {
        User user = userRepository.findById(id)
            .orElseThrow(() -> new EntityNotFoundException("User not found: " + id));
        return toDTO(user);  // private helper method
    }

    private UserDTO toDTO(User user) {  // encapsulated logic
        return new UserDTO(user.getId(), user.getName(), user.getEmail());
    }
}
```

## ✅ Quick Reference — Khi Nào Dùng Gì?

| Tình huống | Giải pháp OOP |
|-----------|--------------|
| Muốn tái sử dụng code từ class khác | **Inheritance** (`extends`) |
| Muốn định nghĩa contract (API) | **Interface** / **Abstraction** |
| Muốn bảo vệ data | **Encapsulation** (`private` + getters/setters) |
| Cùng method, khác hành vi theo loại | **Polymorphism** (Override) |
