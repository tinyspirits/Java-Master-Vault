## 🚫 Vấn Đề: NullPointerException

```java
// ❌ Nguy hiểm — có thể NPE
User user = userRepository.findByEmail("alice@example.com");
String city = user.getAddress().getCity().toUpperCase(); // NPE nếu bất kỳ thứ gì null!
```

## ✅ Giải Pháp: Optional<T>

```java
// Optional là container có thể chứa hoặc không chứa value
Optional<User> userOpt = userRepository.findByEmail("alice@example.com");

// Kiểm tra và lấy giá trị
if (userOpt.isPresent()) {
    System.out.println(userOpt.get().getName());
}

// Elegant API
userOpt.ifPresent(u -> System.out.println(u.getName()));

// orElse — giá trị mặc định nếu empty
User user = userOpt.orElse(User.anonymous());

// orElseGet — lazy, chỉ gọi supplier khi empty
User user2 = userOpt.orElseGet(() -> createDefaultUser());

// orElseThrow — throw exception nếu empty
User user3 = userOpt.orElseThrow(() -> new UserNotFoundException("Not found"));

// map — transform value nếu present
Optional<String> nameOpt = userOpt.map(User::getName);
Optional<String> upperName = userOpt
    .map(User::getName)
    .map(String::toUpperCase);

// flatMap — khi mapper trả về Optional
Optional<String> city = userOpt
    .flatMap(u -> Optional.ofNullable(u.getAddress()))
    .flatMap(a -> Optional.ofNullable(a.getCity()));

// filter
Optional<User> adminUser = userOpt.filter(u -> u.getRole() == Role.ADMIN);
```

## 🏭 Tạo Optional

```java
Optional<String> empty    = Optional.empty();
Optional<String> present  = Optional.of("Hello");        // NPE nếu null!
Optional<String> nullable = Optional.ofNullable(null);   // safe, tạo empty nếu null
```

---

## ⚠️ Anti-Patterns

```java
// ❌ Chống - Optional.get() không kiểm tra
Optional<User> opt = findUser(id);
User user = opt.get();  // NoSuchElementException nếu empty!

// ❌ Chống - dùng Optional như null check thuần
if (opt.isPresent()) {
    User u = opt.get();  // thay bằng opt.ifPresent() hoặc opt.map()
}

// ❌ Chống - Optional làm parameter (dùng @Nullable thay thế)
public void process(Optional<String> name) { ... }  // không nên

// ✅ Optional phù hợp nhất làm return type
public Optional<User> findByEmail(String email) { ... }
```
