## 🆚 So Sánh Tổng Quan

| | Interface | Abstract Class |
|--|-----------|---------------|
| Từ khóa | `interface` / `implements` | `abstract class` / `extends` |
| Multiple | ✅ Class implements nhiều Interface | ❌ Chỉ extends 1 class |
| Constructor | ❌ Không có | ✅ Có |
| Fields | Chỉ `public static final` | Mọi loại field |
| Methods | `default`, `static`, `abstract` | Mọi loại method |
| Khi nào dùng | Định nghĩa **contract/API** | Chia sẻ **code chung** + buộc override |

## 📋 Interface

```java
// Định nghĩa contract
public interface Payable {
    // Abstract method — phải implement
    void processPayment(double amount);
    double getBalance();

    // Default method (Java 8+) — có implementation mặc định
    default String getPaymentStatus() {
        return getBalance() > 0 ? "ACTIVE" : "INACTIVE";
    }

    // Static method — gọi qua tên Interface
    static Payable createCreditCard(double limit) {
        return new CreditCard(limit);
    }
}

// Một class implements nhiều interfaces
public class CreditCard implements Payable, Printable, Serializable {
    private double balance;

    public CreditCard(double initialBalance) {
        this.balance = initialBalance;
    }

    @Override
    public void processPayment(double amount) {
        if (amount > balance) throw new InsufficientFundsException();
        this.balance -= amount;
    }

    @Override
    public double getBalance() { return balance; }
    
    // getPaymentStatus() kế thừa từ default method của Payable
}
```

### Functional Interface (Java 8+)

```java
// Interface chỉ có đúng 1 abstract method → dùng được với Lambda
@FunctionalInterface
public interface Validator<T> {
    boolean validate(T value);
}

// Sử dụng với lambda
Validator<String> notEmpty = s -> !s.isEmpty();
Validator<Integer> positive = n -> n > 0;

System.out.println(notEmpty.validate("Hello")); // true
System.out.println(positive.validate(-5));      // false
```

## 🏛️ Abstract Class

```java
// Khi có code chung + buộc subclass implement một số method
public abstract class ReportGenerator {
    // Shared field
    protected String reportTitle;
    protected LocalDate generatedDate;

    public ReportGenerator(String title) {
        this.reportTitle = title;
        this.generatedDate = LocalDate.now();
    }

    // Template Method Pattern — định nghĩa "khung" quy trình
    public final String generate() {  // final — không cho override
        String header = buildHeader();
        String body = buildBody();    // abstract — subclass tự làm
        String footer = buildFooter();
        return header + "\n" + body + "\n" + footer;
    }

    // Concrete shared methods
    protected String buildHeader() {
        return "=== " + reportTitle + " ===\nDate: " + generatedDate;
    }

    protected String buildFooter() {
        return "--- End of Report ---";
    }

    // Abstract — BẮT BUỘC subclass phải implement
    protected abstract String buildBody();
}

public class SalesReport extends ReportGenerator {
    private List<Sale> sales;

    public SalesReport(List<Sale> sales) {
        super("Sales Report");
        this.sales = sales;
    }

    @Override
    protected String buildBody() {
        return sales.stream()
            .map(s -> s.product() + ": $" + s.amount())
            .collect(Collectors.joining("\n"));
    }
}
```

## 🎯 Quy Tắc Lựa Chọn

```
Câu hỏi: "Đây là HỢP ĐỒNG (CÁI GÌ) hay KẾ THỪA CODE (NHƯ THẾ NÀO)?"
    ↓
Hợp đồng/API → Interface
Chia sẻ implementation → Abstract Class

Ví dụ thực tế:
- UserRepository    → Interface (Spring Data định nghĩa contract)
- BaseEntity        → Abstract Class (chứa id, createdAt, updatedAt chung)
- Comparable<T>     → Interface (contract "có thể so sánh")
- HttpServlet       → Abstract Class (chia sẻ HTTP handling code)
```
