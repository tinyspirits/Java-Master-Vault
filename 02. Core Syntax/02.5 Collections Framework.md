## 🗺️ Collections Hierarchy

```
Iterable
  └── Collection
        ├── List          → ArrayList, LinkedList, Vector
        ├── Set           → HashSet, LinkedHashSet, TreeSet
        └── Queue         → LinkedList, PriorityQueue, ArrayDeque

Map (không extends Collection)
  ├── HashMap
  ├── LinkedHashMap
  ├── TreeMap
  └── Hashtable (legacy)
```

---

## 📋 List — Ordered, Allows Duplicates

```java
// ArrayList — fast random access, slow insert/delete at middle
List<String> list = new ArrayList<>();
list.add("Apple");
list.add("Banana");
list.add("Apple");     // duplicates OK
list.add(1, "Mango");  // insert at index

System.out.println(list.get(0));   // "Apple"
System.out.println(list.size());   // 4
list.remove("Banana");
list.remove(0);  // remove by index

// Immutable list (Java 9+)
List<String> immutable = List.of("A", "B", "C");
// immutable.add("D"); ❌ UnsupportedOperationException

// Sort
List<Integer> nums = new ArrayList<>(List.of(3, 1, 4, 1, 5, 9));
Collections.sort(nums);                      // [1, 1, 3, 4, 5, 9]
nums.sort(Comparator.reverseOrder());        // [9, 5, 4, 3, 1, 1]
```

## 🔵 Set — Unique Elements, No Duplicates

```java
// HashSet — O(1) add/remove/contains, unordered
Set<String> hashSet = new HashSet<>();
hashSet.add("Apple");
hashSet.add("Banana");
hashSet.add("Apple");  // bị ignore!
System.out.println(hashSet.size()); // 2

// LinkedHashSet — giữ insertion order
Set<String> linked = new LinkedHashSet<>(List.of("C", "A", "B", "A"));
System.out.println(linked);  // [C, A, B]

// TreeSet — sorted order
Set<Integer> sorted = new TreeSet<>(List.of(5, 2, 8, 1, 9, 3));
System.out.println(sorted);  // [1, 2, 3, 5, 8, 9]

// Set operations
Set<Integer> setA = new HashSet<>(Set.of(1, 2, 3, 4));
Set<Integer> setB = new HashSet<>(Set.of(3, 4, 5, 6));

setA.retainAll(setB);  // Intersection: [3, 4]
setA.addAll(setB);     // Union
setA.removeAll(setB);  // Difference
```

## 🗝️ Map — Key-Value Pairs

```java
// HashMap — O(1) get/put, unordered
Map<String, Integer> scores = new HashMap<>();
scores.put("Alice", 95);
scores.put("Bob", 87);
scores.put("Alice", 98);  // overwrite!

scores.get("Alice");                    // 98
scores.getOrDefault("Charlie", 0);      // 0 (key không tồn tại)
scores.containsKey("Bob");              // true

// putIfAbsent, computeIfAbsent
scores.putIfAbsent("Dave", 75);        // chỉ put nếu chưa có
scores.computeIfAbsent("Eve", k -> 80); // tính toán value nếu chưa có

// Iterate
scores.forEach((name, score) ->
    System.out.println(name + ": " + score));

for (Map.Entry<String, Integer> entry : scores.entrySet()) {
    System.out.println(entry.getKey() + " → " + entry.getValue());
}

// LinkedHashMap — giữ insertion order
Map<String, String> config = new LinkedHashMap<>();

// TreeMap — sorted by key
Map<String, Integer> sorted = new TreeMap<>(scores);
```

## ⚡ Chọn Đúng Collection

```
Cần ordered + duplicates?  → List (ArrayList nếu access nhiều, LinkedList nếu insert/delete nhiều)
Cần unique?                → Set (HashSet nhanh nhất, TreeSet nếu cần sort)
Cần key-value?             → Map (HashMap nhanh, TreeMap nếu cần sort by key)
Cần thread-safe?           → ConcurrentHashMap, CopyOnWriteArrayList
```
