## 📦 Primitive Types

| Type | Size | Default | Range / Example |
|------|------|---------|----------------|
| `byte` | 1 byte | 0 | -128 → 127 |
| `short` | 2 bytes | 0 | -32,768 → 32,767 |
| `int` | 4 bytes | 0 | -2^31 → 2^31-1 |
| `long` | 8 bytes | 0L | -2^63 → 2^63-1 |
| `float` | 4 bytes | 0.0f | ~7 decimal digits |
| `double` | 8 bytes | 0.0 | ~15 decimal digits |
| `boolean` | 1 bit | false | true / false |
| `char` | 2 bytes | '\u0000' | Unicode character |

```java
int age = 25;
long population = 8_000_000_000L;   // underscore cho dễ đọc
double pi = 3.14159;
boolean isActive = true;
char grade = 'A';
```

## 📦 Reference Types

```java
// String — immutable, special treatment
String name = "Alice";
String name2 = new String("Alice");  // khác reference, same value
System.out.println(name == name2);       // false (so sánh reference)
System.out.println(name.equals(name2));  // true (so sánh value) ✅

// Arrays
int[] scores = {90, 85, 92, 78};
String[] fruits = new String[3];
fruits[0] = "Apple";

// Objects
LocalDate today = LocalDate.now();
```

## 🔑 var Keyword (Java 10+)

```java
// Type inference — compiler tự suy ra kiểu
var name = "Alice";           // inferred: String
var count = 42;               // inferred: int
var users = new ArrayList<String>(); // inferred: ArrayList<String>

// ⚠️ var chỉ dùng được cho local variable, phải có initializer
// var x;  ❌ Lỗi - không có initializer
```

## 🔢 Type Conversion

```java
// Widening (tự động, an toàn)
int i = 100;
long l = i;      // int → long ✅
double d = i;    // int → double ✅

// Narrowing (phải cast rõ ràng, có thể mất dữ liệu)
double pi = 3.14;
int approx = (int) pi;  // → 3 (mất phần thập phân)

// String conversion
int num = 42;
String s = String.valueOf(num);   // "42"
String s2 = Integer.toString(num); // "42"
int back = Integer.parseInt("42"); // 42
```
