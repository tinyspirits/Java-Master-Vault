## 🔀 if / else if / else

```java
int score = 75;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else if (score >= 70) {
    System.out.println("C");
} else {
    System.out.println("F");
}

// Ternary operator
String result = score >= 60 ? "Pass" : "Fail";
```

## 🔀 switch (Classic & Modern)

```java
// Classic switch
String day = "MONDAY";
switch (day) {
    case "MONDAY":
    case "TUESDAY":
        System.out.println("Weekday");
        break;
    case "SATURDAY":
    case "SUNDAY":
        System.out.println("Weekend");
        break;
    default:
        System.out.println("Unknown");
}

// ✅ Switch Expression (Java 14+) — ngắn gọn hơn
String type = switch (day) {
    case "MONDAY", "TUESDAY", "WEDNESDAY", "THURSDAY", "FRIDAY" -> "Weekday";
    case "SATURDAY", "SUNDAY" -> "Weekend";
    default -> throw new IllegalArgumentException("Invalid day: " + day);
};
```

## 🔁 Loops

```java
// for
for (int i = 0; i < 5; i++) {
    System.out.println(i);  // 0,1,2,3,4
}

// for-each (dùng với Iterable)
List<String> names = List.of("Alice", "Bob", "Charlie");
for (String name : names) {
    System.out.println(name);
}

// while
int count = 0;
while (count < 5) {
    System.out.println(count++);
}

// do-while — chạy ít nhất 1 lần
int n = 0;
do {
    System.out.println("Runs at least once: " + n);
    n++;
} while (n < 0);

// break & continue
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;  // bỏ qua 3
    if (i == 7) break;     // dừng ở 7
    System.out.print(i + " ");  // 0 1 2 4 5 6
}
```
