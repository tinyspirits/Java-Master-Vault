## 💡 Lambda là gì?

Lambda Expression (Java 8+) là cách viết **anonymous function** ngắn gọn — thay thế anonymous inner class cho Functional Interface.

```java
// ❌ Cũ — Anonymous Inner Class
Comparator<String> comp = new Comparator<String>() {
    @Override
    public int compare(String a, String b) {
        return a.compareTo(b);
    }
};

// ✅ Lambda
Comparator<String> comp = (a, b) -> a.compareTo(b);

// Còn ngắn hơn với Method Reference
Comparator<String> comp = String::compareTo;
```

## 📝 Cú Pháp Lambda

```java
// (parameters) -> expression
(int x, int y) -> x + y

// (parameters) -> { statements }
(String s) -> {
    String result = s.toUpperCase();
    return result;
}

// Không có parameter
() -> System.out.println("Hello!")

// Một parameter — có thể bỏ ngoặc
s -> s.length()
```

## 🏭 Built-in Functional Interfaces (java.util.function)

```java
// Function<T, R> — nhận T, trả R
Function<String, Integer> strlen = s -> s.length();
Function<Integer, Integer> doubled = n -> n * 2;
// Compose
Function<String, Integer> composed = strlen.andThen(doubled);
System.out.println(composed.apply("Hello")); // 10

// Predicate<T> — nhận T, trả boolean
Predicate<String> isEmpty = String::isEmpty;
Predicate<String> isLong = s -> s.length() > 5;
Predicate<String> isNotEmpty = isEmpty.negate();
Predicate<String> combined = isNotEmpty.and(isLong);

// Consumer<T> — nhận T, không trả
Consumer<String> printer = System.out::println;
Consumer<String> logger = s -> log.info("Value: {}", s);
printer.andThen(logger).accept("Hello"); // print rồi log

// Supplier<T> — không nhận, trả T
Supplier<LocalDate> today = LocalDate::now;
Supplier<List<String>> listFactory = ArrayList::new;

// BiFunction<T, U, R> — nhận 2 tham số
BiFunction<String, Integer, String> repeat = (s, n) -> s.repeat(n);
System.out.println(repeat.apply("Ha", 3)); // "HaHaHa"
```

## 🔗 Method References

```java
// 4 loại method reference
// 1. Static method
Function<String, Integer> parser = Integer::parseInt;

// 2. Instance method trên object cụ thể
String prefix = "Hello, ";
Function<String, String> greeter = prefix::concat;

// 3. Instance method trên type (tham số đầu là receiver)
Function<String, String> upper = String::toUpperCase;
Comparator<String> comp = String::compareTo;

// 4. Constructor reference
Supplier<ArrayList<String>> listMaker = ArrayList::new;
Function<String, StringBuilder> sbMaker = StringBuilder::new;
```

## 🌍 Capturing Variables (Closure)

```java
String prefix = "Mr. ";  // effectively final

// Lambda capture biến ngoài — biến phải effectively final
Function<String, String> addPrefix = name -> prefix + name;
System.out.println(addPrefix.apply("Smith")); // "Mr. Smith"

// prefix = "Dr. ";  ❌ Lỗi nếu uncomment — không thể thay đổi sau khi capture
```
