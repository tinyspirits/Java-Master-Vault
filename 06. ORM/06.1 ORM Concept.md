## ❓ Vấn Đề: Object-Relational Impedance Mismatch

Java là **Object-Oriented** (OOP) nhưng Database là **Relational** (Tables/Rows).

```
Java World                      Database World
────────────────────────────    ────────────────────────
class User {                    TABLE users (
    Long id;               ↔        id BIGINT PRIMARY KEY,
    String name;           ↔        name VARCHAR(100),
    String email;          ↔        email VARCHAR(255),
    List<Order> orders;    ↔        (separate orders table + FK)
}                               );
```

**Vấn đề khi dùng JDBC thuần:**

```java
// ❌ JDBC thuần — verbose, error-prone, không type-safe
Connection conn = dataSource.getConnection();
PreparedStatement ps = conn.prepareStatement(
    "SELECT id, name, email FROM users WHERE id = ?"
);
ps.setLong(1, userId);
ResultSet rs = ps.executeQuery();

User user = null;
if (rs.next()) {
    user = new User();
    user.setId(rs.getLong("id"));
    user.setName(rs.getString("name"));
    user.setEmail(rs.getString("email"));
    // ... mapping thủ công, boilerplate code
}
rs.close();
ps.close();
conn.close();
```

## ✅ Giải Pháp: ORM

**ORM (Object-Relational Mapping)** là kỹ thuật tự động ánh xạ giữa Objects và Database Tables:

```java
// ✅ JPA/Hibernate — đơn giản, type-safe
@Entity
public class User {
    @Id Long id;
    String name;
    String email;
}

// Chỉ cần gọi:
User user = entityManager.find(User.class, userId);
// Hibernate tự sinh SQL, tự map kết quả
```

## 🏗️ JPA vs Hibernate

```
JPA (Jakarta Persistence API)
  ↑ là SPECIFICATION (interface/contract)
  ↑ định nghĩa annotations, API

Hibernate
  ↑ là IMPLEMENTATION của JPA
  ↑ là ORM framework thực sự làm việc

Spring Data JPA
  ↑ layer trên JPA/Hibernate
  ↑ cung cấp Repository pattern, giảm boilerplate tối đa
```

## ⚡ Tại Sao Dùng ORM?

| Tiêu chí | JDBC thuần | JPA/Hibernate |
|---------|-----------|--------------|
| Code lượng | ❌ Nhiều boilerplate | ✅ Ngắn gọn |
| Type safety | ❌ Dùng String SQL | ✅ Java types |
| Database portability | ❌ SQL dialect khác nhau | ✅ Tự generate |
| Caching | ❌ Tự implement | ✅ Built-in L1/L2 cache |
| Lazy loading | ❌ Tự implement | ✅ Tự động |
| Learning curve | ✅ Dễ hiểu | ❌ Phải học |
| Complex queries | ✅ Full SQL control | ❌ Có thể tricky |
