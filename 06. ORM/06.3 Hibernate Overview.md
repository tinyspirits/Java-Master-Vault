## 🏗️ Hibernate là gì?

**Hibernate** là ORM framework phổ biến nhất cho Java — là **implementation** của JPA specification. Khi bạn dùng Spring Data JPA, Hibernate là engine chạy phía sau.

---

## 🔄 Session & Persistence Context

```java
// EntityManager = JPA interface
// Session = Hibernate-specific interface (mạnh hơn)

@Repository
public class UserDao {
    @PersistenceContext
    private EntityManager em;  // = Hibernate Session

    // CRUD operations
    public User save(User user) {
        em.persist(user);   // INSERT
        return user;
    }

    public User find(Long id) {
        return em.find(User.class, id);  // SELECT
    }

    public void update(User user) {
        em.merge(user);  // UPDATE
    }

    public void delete(Long id) {
        User user = em.find(User.class, id);
        em.remove(user);  // DELETE
    }
}
```

---

## 📊 Entity States

```
new User()          → TRANSIENT   (không liên quan đến DB, không tracking)
em.persist(user)    → MANAGED     (trong Persistence Context, tracking changes)
em.detach(user)     → DETACHED    (ra khỏi context, changes không tracked)
em.remove(user)     → REMOVED     (sẽ bị DELETE khi flush)

        TRANSIENT
            ↓ persist()
        MANAGED ←──── merge()  ←── DETACHED
            ↓ remove()               ↑ detach() / close session
        REMOVED         ──────────────
```

## ⚡ Caching

```
L1 Cache (First Level)  — mặc định, per Session/EntityManager
    └── Trong 1 transaction, cùng entity không query DB 2 lần

L2 Cache (Second Level) — cần config, per SessionFactory
    └── Dùng chung giữa các sessions (Ehcache, Caffeine, Redis)
    └── @Cacheable annotation
```

## 🔍 JPQL & Criteria API

```java
// JPQL — Java Persistence Query Language (OOP style)
List<User> users = em.createQuery(
    "SELECT u FROM User u WHERE u.status = :status ORDER BY u.name",
    User.class
).setParameter("status", UserStatus.ACTIVE).getResultList();

// Criteria API — programmatic, type-safe
CriteriaBuilder cb = em.getCriteriaBuilder();
CriteriaQuery<User> cq = cb.createQuery(User.class);
Root<User> root = cq.from(User.class);

cq.select(root)
  .where(cb.equal(root.get("status"), UserStatus.ACTIVE))
  .orderBy(cb.asc(root.get("name")));

List<User> result = em.createQuery(cq).getResultList();
```

## ⚠️ N+1 Problem & Solution

```java
// ❌ N+1 Problem — 1 query lấy users + N queries lấy orders
List<User> users = userRepository.findAll();  // 1 query
for (User user : users) {
    user.getOrders().size();  // N queries! (1 per user)
}

// ✅ Fix 1: JOIN FETCH
@Query("SELECT u FROM User u LEFT JOIN FETCH u.orders")
List<User> findAllWithOrders();

// ✅ Fix 2: @EntityGraph
@EntityGraph(attributePaths = {"orders"})
List<User> findAll();

// ✅ Fix 3: EAGER loading (dùng cẩn thận)
@OneToMany(fetch = FetchType.EAGER)
private List<Order> orders;
```
