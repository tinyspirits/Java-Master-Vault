## 🏷️ Core Annotations

| Annotation | Mô tả |
|-----------|-------|
| `@Test` | Đánh dấu method là test case |
| `@BeforeEach` | Chạy trước MỖI test |
| `@AfterEach` | Chạy sau MỖI test |
| `@BeforeAll` | Chạy 1 lần trước tất cả tests (phải `static`) |
| `@AfterAll` | Chạy 1 lần sau tất cả tests (phải `static`) |
| `@Disabled` | Tắt test tạm thời |
| `@DisplayName` | Tên hiển thị dễ đọc |
| `@Nested` | Nhóm tests liên quan |
| `@ParameterizedTest` | Test với nhiều input |

## ✍️ Viết Test Cơ Bản — Cấu Trúc AAA

```java
package com.example.service;

import org.junit.jupiter.api.*;
import static org.junit.jupiter.api.Assertions.*;

@DisplayName("UserService Tests")
class UserServiceTest {

    private UserService userService;

    @BeforeEach
    void setUp() {
        // Arrange — setup trước mỗi test
        userService = new UserServiceImpl();
    }

    @AfterEach
    void tearDown() {
        // Cleanup sau mỗi test (nếu cần)
    }

    @Test
    @DisplayName("Should return user when valid ID provided")
    void findById_ValidId_ReturnsUser() {
        // Arrange
        Long userId = 1L;

        // Act
        UserResponse result = userService.findById(userId);

        // Assert
        assertNotNull(result);
        assertEquals(userId, result.id());
        assertEquals("Alice", result.name());
    }

    @Test
    @DisplayName("Should throw exception when user not found")
    void findById_InvalidId_ThrowsException() {
        // Act & Assert
        EntityNotFoundException exception = assertThrows(
            EntityNotFoundException.class,
            () -> userService.findById(999L)
        );

        assertEquals("User not found: 999", exception.getMessage());
    }
}
```

## 🔍 Assertions — Kiểm Tra Kết Quả

```java
import static org.junit.jupiter.api.Assertions.*;

// Equality
assertEquals(expected, actual);
assertEquals(3.14, result, 0.001);  // double với tolerance
assertNotEquals(unexpected, actual);

// Null checks
assertNull(value);
assertNotNull(value);

// Boolean
assertTrue(condition);
assertFalse(condition);

// Exception
assertThrows(IllegalArgumentException.class, () -> service.create(null));

// Collections
assertIterableEquals(expectedList, actualList);  // same elements, same order

// Multiple assertions — tất cả chạy dù có fail
assertAll("User properties",
    () -> assertEquals("Alice", user.getName()),
    () -> assertEquals("alice@example.com", user.getEmail()),
    () -> assertTrue(user.isActive())
);

// AssertJ — fluent, dễ đọc hơn (cũng có sẵn trong spring-boot-starter-test)
import static org.assertj.core.api.Assertions.*;

assertThat(result).isNotNull();
assertThat(result.getName()).isEqualTo("Alice").startsWith("A");
assertThat(list).hasSize(3).contains("Apple", "Banana");
assertThat(exception).isInstanceOf(EntityNotFoundException.class)
                      .hasMessageContaining("not found");
```

## 🔁 Parameterized Tests

```java
import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.*;

class EmailValidatorTest {

    private EmailValidator validator = new EmailValidator();

    @ParameterizedTest(name = "Email ''{0}'' should be valid: {1}")
    @CsvSource({
        "alice@example.com, true",
        "invalid-email,     false",
        "no-at-sign.com,    false",
        "user@domain.org,   true"
    })
    void validate_Email_ReturnsExpected(String email, boolean expected) {
        assertEquals(expected, validator.isValid(email));
    }

    @ParameterizedTest
    @ValueSource(strings = {"", " ", "  "})
    void validate_BlankEmail_ReturnsFalse(String email) {
        assertFalse(validator.isValid(email));
    }

    @ParameterizedTest
    @NullSource  // test với null
    void validate_NullEmail_ReturnsFalse(String email) {
        assertFalse(validator.isValid(email));
    }

    @ParameterizedTest
    @MethodSource("provideInvalidEmails")
    void validate_InvalidEmails_ReturnsFalse(String email) {
        assertFalse(validator.isValid(email));
    }

    static Stream<String> provideInvalidEmails() {
        return Stream.of("noDomain@", "@noUser.com", "spaces in@email.com");
    }
}
```

## 🗂️ Nested Tests — Nhóm Tests Liên Quan

```java
@DisplayName("BankAccount")
class BankAccountTest {

    private BankAccount account;

    @BeforeEach
    void setUp() {
        account = new BankAccount("Alice", 1000.0);
    }

    @Nested
    @DisplayName("When depositing money")
    class Deposit {
        @Test
        void increasesBalance() {
            account.deposit(500);
            assertEquals(1500, account.getBalance());
        }

        @Test
        void throwsOnNegativeAmount() {
            assertThrows(IllegalArgumentException.class,
                () -> account.deposit(-100));
        }
    }

    @Nested
    @DisplayName("When withdrawing money")
    class Withdraw {
        @Test
        void decreasesBalance() {
            account.withdraw(200);
            assertEquals(800, account.getBalance());
        }

        @Test
        void throwsWhenInsufficientFunds() {
            assertThrows(IllegalStateException.class,
                () -> account.withdraw(2000));
        }
    }
}
```
