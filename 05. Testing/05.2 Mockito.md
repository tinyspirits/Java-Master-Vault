## 🎭 Mockito là gì?

**Mockito** là framework tạo **Mock objects** — giả lập behavior của dependencies để test một class **isolation** (không phụ thuộc vào database, HTTP, etc.).

---

## 🏷️ Core Annotations

| Annotation | Mô tả |
|-----------|-------|
| `@Mock` | Tạo mock object |
| `@InjectMocks` | Tạo object và inject tất cả @Mock vào |
| `@Spy` | Wrap real object, override một số method |
| `@Captor` | Capture argument truyền vào mock |
| `@ExtendWith(MockitoExtension.class)` | Kích hoạt Mockito với JUnit 5 |

## ✍️ Test Service với Mockito

```java
@ExtendWith(MockitoExtension.class)
@DisplayName("UserService Unit Tests")
class UserServiceTest {

    @Mock
    private UserRepository userRepository;  // Mock — không real DB

    @Mock
    private UserMapper userMapper;

    @InjectMocks
    private UserServiceImpl userService;  // Real class, inject mocks vào

    // ===== findById =====

    @Test
    @DisplayName("findById: Should return UserResponse when user exists")
    void findById_UserExists_ReturnsResponse() {
        // Arrange
        Long userId = 1L;
        User mockUser = new User(userId, "Alice", "alice@example.com");
        UserResponse expectedResponse = new UserResponse(userId, "Alice", "alice@example.com", "ACTIVE");

        when(userRepository.findById(userId)).thenReturn(Optional.of(mockUser));
        when(userMapper.toResponse(mockUser)).thenReturn(expectedResponse);

        // Act
        UserResponse result = userService.findById(userId);

        // Assert
        assertNotNull(result);
        assertEquals("Alice", result.name());
        assertEquals("alice@example.com", result.email());

        // Verify interactions
        verify(userRepository, times(1)).findById(userId);
        verify(userMapper, times(1)).toResponse(mockUser);
        verifyNoMoreInteractions(userRepository, userMapper);
    }

    @Test
    @DisplayName("findById: Should throw exception when user not found")
    void findById_UserNotFound_ThrowsException() {
        // Arrange
        Long userId = 999L;
        when(userRepository.findById(userId)).thenReturn(Optional.empty());

        // Act & Assert
        EntityNotFoundException ex = assertThrows(
            EntityNotFoundException.class,
            () -> userService.findById(userId)
        );

        assertThat(ex.getMessage()).contains("999");
        verify(userRepository).findById(userId);
        verifyNoInteractions(userMapper);  // mapper không được gọi
    }

    // ===== create =====

    @Test
    @DisplayName("create: Should save and return new user")
    void create_ValidRequest_SavesAndReturnsUser() {
        // Arrange
        CreateUserRequest request = new CreateUserRequest("Bob", "bob@example.com");
        User entity = new User(null, "Bob", "bob@example.com");
        User saved = new User(2L, "Bob", "bob@example.com");
        UserResponse expected = new UserResponse(2L, "Bob", "bob@example.com", "ACTIVE");

        when(userRepository.existsByEmail(request.email())).thenReturn(false);
        when(userMapper.toEntity(request)).thenReturn(entity);
        when(userRepository.save(entity)).thenReturn(saved);
        when(userMapper.toResponse(saved)).thenReturn(expected);

        // Act
        UserResponse result = userService.create(request);

        // Assert
        assertThat(result.id()).isEqualTo(2L);
        assertThat(result.name()).isEqualTo("Bob");

        // Verify save was called with correct entity
        verify(userRepository).save(entity);
    }

    @Test
    @DisplayName("create: Should throw when email already exists")
    void create_DuplicateEmail_ThrowsException() {
        // Arrange
        CreateUserRequest request = new CreateUserRequest("Alice2", "alice@example.com");
        when(userRepository.existsByEmail(request.email())).thenReturn(true);

        // Act & Assert
        assertThrows(DuplicateEmailException.class, () -> userService.create(request));

        // Verify save was NEVER called
        verify(userRepository, never()).save(any());
    }
}
```

## 🔧 Stubbing Nâng Cao

```java
// thenReturn multiple values — mỗi lần gọi trả giá trị khác
when(repository.count())
    .thenReturn(0L)   // lần 1
    .thenReturn(1L)   // lần 2
    .thenReturn(2L);  // lần 3+

// thenThrow — giả lập exception
when(repository.findById(any())).thenThrow(new DataAccessException("DB error"));

// doAnswer — custom logic
doAnswer(invocation -> {
    User user = invocation.getArgument(0);
    user.setId(100L);  // simulate auto-generated ID
    return user;
}).when(repository).save(any(User.class));

// ArgumentCaptor — capture argument để assert
@Captor
ArgumentCaptor<User> userCaptor;

verify(repository).save(userCaptor.capture());
User capturedUser = userCaptor.getValue();
assertEquals("Alice", capturedUser.getName());
assertNull(capturedUser.getId());  // trước khi save, ID chưa có
```

## 🎯 Argument Matchers

```java
// any() matchers
when(repo.findById(anyLong())).thenReturn(Optional.of(user));
when(repo.findByName(anyString())).thenReturn(List.of());
when(mapper.toEntity(any(CreateUserRequest.class))).thenReturn(entity);

// Specific matchers
when(repo.findById(eq(1L))).thenReturn(Optional.of(user));

// Custom matcher
when(repo.save(argThat(u -> u.getName().startsWith("A")))).thenReturn(savedUser);
```
